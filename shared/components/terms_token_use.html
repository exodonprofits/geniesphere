Terms of Token Use

These terms govern how digital tokens are used within the GenieSphere platform.

1. What Are Tokens?

Tokens are digital credits used to access AI tools and features on GenieSphere. Each time you use a premium tool, tokens may be deducted from your balance.

2. Token Cost Per Use

  • Basic tools: typically 1 token per session
  • Advanced tools (e.g. stock analysis, automation): 2–5 tokens
  • Free tools: labeled clearly and cost 0 tokens

3. Token Expiration

Tokens do not currently expire. This may change in future with notice.

4. Refunds & Issues

  • Tokens are non-refundable once spent
  • If a tool fails to function after token use, contact support for review
  • We may credit tokens back if technical errors are confirmed

5. Token Abuse

Abuse includes exploiting free trials, generating automated token usage, or fraud. GenieSphere may revoke access or tokens in such cases.

6. Updates

We reserve the right to adjust pricing, value, or structure of token use at any time. Updates will be published on this page.

GenieSphere is currently in beta. All token rules are subject to refinement before full launch.
